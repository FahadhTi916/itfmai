# ITFM AI Website

Redesigned static HTML website for GitHub and Vercel.

## Deploy on Vercel
1. Upload `index.html`, `vercel.json`, and `README.md` to your GitHub repository.
2. In Vercel, choose **Add New → Project** and import the GitHub repository.
3. Choose **Other** as the framework preset.
4. Deploy the static site.

## Footer
The centered black footer includes the requested YouTube, Facebook, Instagram, ITFM AI website, powered-by, admin, and 2027 copyright text.

## Important
This is a static front-end website. Real AI image/video/audio generation, AI chat responses, and live channel streaming require the relevant backend/API integrations and credentials. Do not put secret API keys in `index.html`.
