ITFM AI — ആദ്യം വായിക്കുക
========================

ഈ ZIP-ൽ ITFM AI പ്രോജക്റ്റിന്റെ ഫയലുകൾ ഒരുമിച്ച് നൽകിയിരിക്കുന്നു.

പ്രധാനമായി അറിയുക:
- ഇത് പൂർണ്ണമായി deploy ചെയ്ത live website അല്ല.
- API keys സൃഷ്ടിക്കുന്ന ഫീച്ചർ പ്രവർത്തിക്കാൻ Supabase project, Auth, SQL schema, server environment variables എന്നിവ സജ്ജമാക്കണം.
- AI Image/Video/Audio/Music/Cover/STEM/Genjutsu എന്നിവയ്ക്ക് provider-specific API അല്ലെങ്കിൽ സ്വന്തം server-ൽ പ്രവർത്തിക്കുന്ന model വേണം. ഇവ ഈ ZIP-ൽ എല്ലാം live ആയി ബന്ധിപ്പിച്ചിട്ടില്ല.
- ITFM AI key എന്നത് നിങ്ങളുടെ platform-ൽ ഉപയോക്താക്കൾക്ക് നൽകുന്ന key ആണ്; അത് പുറത്തുള്ള AI provider-ന്റെ key-ന് പകരമല്ല.

ഫയലുകൾ:
- index.html                 പ്രധാന വെബ് UI
- keys.html                  API key management UI
- api/index.js               backend API routes
- api/[...path].js           Vercel route handler
- supabase/schema.sql        database schema
- .env.example               environment variables മാതൃക
- vercel.json                Vercel config
- README.md                  വിശദമായ setup നിർദേശങ്ങൾ

ആരംഭിക്കാൻ:
1. ZIP extract ചെയ്യുക.
2. GitHub repository-ലേക്ക് ഉള്ളടക്കം upload ചെയ്യുക.
3. Supabase project സൃഷ്ടിച്ച് Email Auth enable ചെയ്യുക.
4. supabase/schema.sql SQL Editor-ൽ run ചെയ്യുക.
5. Vercel-ൽ repository import ചെയ്ത് deploy ചെയ്യുക.
6. README.md അനുസരിച്ച് Environment Variables ചേർക്കുക.
7. /api/health, /keys.html എന്നിവ പരിശോധിക്കുക.

സുരക്ഷ:
- SUPABASE_SERVICE_ROLE_KEY browser code-ലോ public repository-ലോ ചേർക്കരുത്.
- യഥാർത്ഥ provider keys-നെ .env.example-ൽ ചേർക്കരുത്.
- Deploy ചെയ്തശേഷം rate limits, usage quotas, abuse protection എന്നിവ ചേർക്കണം.

100% സൗജന്യവും പരിധിയില്ലാത്തതുമായ എല്ലാ AI സേവനങ്ങളും ഉറപ്പാക്കാൻ കഴിയില്ല; ഓരോ provider-ന്റെയും free tier-നും നിബന്ധനകൾക്കും വിധേയമാണ്.
