ITFM AI — NEON DATABASE SETUP (മലയാളം)
======================================

1) Neon-ൽ https://neon.tech/ തുറന്ന് അക്കൗണ്ട് സൃഷ്ടിച്ച് ഒരു PostgreSQL project ഉണ്ടാക്കുക.
2) Neon Dashboard → SQL Editor തുറക്കുക. ZIP-ലുള്ള neon/schema.sql ഉള്ളടക്കം paste ചെയ്ത് Run ചെയ്യുക.
3) Neon Dashboard-ൽ Connect എന്നതിൽ നിന്ന് connection string എടുക്കുക. അതിൽ username/password ഉണ്ട്; രഹസ്യമായി സൂക്ഷിക്കുക.
4) Vercel → നിങ്ങളുടെ project → Settings → Environment Variables എന്നതിൽ ചേർക്കുക:
   DATABASE_URL = Neon connection string (sslmode=require ഉണ്ടായിരിക്കണം)
   JWT_SECRET = നീളമുള്ള random secret (കുറഞ്ഞത് 32 bytes)
   ITFM_AI_API_KEY / ITFM_AI_BASE_URL = AI Chat provider ഉണ്ടെങ്കിൽ മാത്രം
   TMDB_API_KEY = TMDB key ഉണ്ടെങ്കിൽ മാത്രം
5) Save ചെയ്ത് Redeploy ചെയ്യുക.
6) /api/health തുറന്ന് API status നോക്കുക. /keys.html തുറന്ന് Create account → Create API key പരീക്ഷിക്കുക.

സുരക്ഷാ குறிப்பുകൾ:
- DATABASE_URL, JWT_SECRET, provider API keys എന്നിവကို HTML/JavaScript-ൽ ഇടരുത്. Vercel server-side Environment Variables-ൽ മാത്രം ഇടുക.
- API key പൂർണ്ണമായി ഒരിക്കൽ മാത്രം കാണിക്കും; സുരക്ഷിതമായി copy ചെയ്യുക.
- Neon database-ലേക്ക് യഥാർത്ഥ connection string നൽകിയിട്ടില്ലാത്തതിനാൽ ഈ ZIP-ൽ നിന്ന് ഇവിടെനിന്ന് live connection/Deployment നടത്താൻ കഴിഞ്ഞിട്ടില്ല.
- AI Image/Video/Music/Audio/Cover/STEM/Genjutsu provider integration-കൾക്ക് വേറിട്ട യഥാർത്ഥ providers/endpoints ആവശ്യമുണ്ട്.
